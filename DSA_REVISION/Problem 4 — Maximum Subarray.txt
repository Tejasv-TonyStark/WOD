Problem 4 — Maximum Subarray

Pattern: Kadane’s Algorithm

Recognition:

Maximum sum
Contiguous subarray
Need best sum while scanning
At each position: continue previous subarray or start fresh

Core idea:

curr_sum = max(arr[i], curr_sum + arr[i])
best_sum = max(best_sum, curr_sum)

Meaning:

arr[i] → start fresh
curr_sum + arr[i] → continue previous subarray

Code:

def maxSubArray(arr):
    curr_sum = arr[0]
    best_sum = arr[0]

    for i in range(1, len(arr)):
        curr_sum = max(arr[i], curr_sum + arr[i])
        best_sum = max(best_sum, curr_sum)

    return best_sum

Complexity: O(n) time | O(1) space

Main insight:

If the previous running sum hurts the current element, drop it and start a new subarray.

Strike line:

Maximum sum + contiguous subarray → Continue or Start Fresh → Kadane’s Algorithm.
