2)What should the Operating System do with the 300 MB that Program B was using?

When a process terminates, the operating system deallocates the memory occupied by that process and returns it to the pool of free memory. This memory can then be allocated to other processes, improving memory utilization and preventing memory leaks.


3)Does your program know its actual physical RAM address, or does it think it has its own independent memory?

No. A program generates logical (virtual) addresses. The Memory Management Unit (MMU) translates these logical addresses into physical addresses using the page table. This abstraction provides memory protection, isolation, and allows efficient memory management.


4)Suppose I ask you:

Why can't a program directly use a physical address instead of a logical address?

Think from the perspective of:

Security
Flexibility
Multiprogramming


Ans)
Programs use logical addresses instead of physical addresses because logical addressing provides memory protection, allows the operating system to load programs anywhere in physical memory without modifying them, and enables virtual memory. The MMU transparently translates logical addresses into physical addresses.


5)What is the difference between a Logical Address and a Physical Address?
Ans)A logical address is the address generated by the CPU and used by the program during execution. It belongs to the process's virtual address space. A physical address is the actual address in RAM where the data is stored. The Memory Management Unit (MMU) translates logical addresses into physical addresses.


6)What is MMU?
The Memory Management Unit (MMU) is a hardware component between the CPU and main memory. It translates the logical (virtual) addresses generated by the CPU into physical addresses using the page table before accessing RAM.

11)"Why don't modern operating systems use Compile-Time Binding?"

Modern operating systems do not use compile-time binding because the compiler cannot know the actual physical memory location where the program will be loaded. Memory availability changes dynamically, so fixing addresses during compilation would require recompiling the program whenever its load location changes. Execution-time binding with the MMU solves this by translating logical addresses into physical addresses dynamically.




12)Contiguous Memory Allocation is a memory management technique in which each process is allocated one continuous block of physical memory.

14)Internal Fragmentation
Definition

Internal Fragmentation occurs when the allocated memory block is larger than the requested memory, leaving unused space inside the allocated block.



15)External Fragmentation
Definition

External Fragmentation occurs when free memory is scattered into many small non-contiguous blocks, so a large process cannot be allocated even though the total free memory is sufficient.

Sol : Compaction


16)What is compaction?
Compaction is the process of relocating processes in memory so that scattered free memory blocks are combined into one large contiguous block, thereby eliminating external fragmentation.
